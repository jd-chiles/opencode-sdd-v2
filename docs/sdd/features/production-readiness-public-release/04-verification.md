# Verification plan: Production readiness and public release

Status: Debian 12 and Windows validation observed; bounded provider canary passed; account and publication gates remain open

REQ-001: Git worktree fingerprint unit tests plus native runner/engine tests for mutation before/after checks and review; verify one common final digest and stale status after edits.
REQ-002: v1-to-v2 and v2-to-v3 migration tests check history/session/evidence preservation, v3 persistence, stale verification/research flags, explicit verification/refresh without builder replay; malformed/unknown state remains fail-closed.
REQ-003: final verification test proves all task evidence shares one fingerprint; post-verification content change makes status stale.
REQ-004: deterministic Git fixtures cover equal-length repeated dirty edits, staged edits/deletions, nested untracked files, rename, executable-mode changes where supported, symlink targets where supported, commit-stable content, ignored paths, unusual names, repeated calls, and non-repository failure.
REQ-005: `npm run check`, `npm run smoke:pack`, Debian 12 and Windows on Node >=22.14; provider-denied `npm run smoke:host -- <OpenCode executable>` on 2.0.32 and the exact latest v2 at release freeze. Configured CI is distinct from an observed CI run.
REQ-006: package smoke asserts MIT metadata and included LICENSE/CHANGELOG; inspect `npm pack --dry-run --json`; validate documented OpenCode plugin install and separate bootstrap CLI.
REQ-007: inspect workflow permissions, npm OIDC/provenance publication path, tag/version guard, required environment and release gates. Publication itself is not run until approved gates pass.
REQ-008: review `docs/production-readiness.md` against observed local/CI/release evidence and explicitly list unexercised platforms, providers, accounts and publication.
SDD workflow gates: CI must run `doctor` and `check --target verifying` on Debian and Windows. Tagged-release must run `check --target complete` after packaging and host smoke, immediately before publication. Regression tests assert the commands remain wired to the intended workflows.
Dependency maintenance gates: weekly CI runs `npm audit --audit-level=moderate`; tagged publication runs `npm audit --omit=dev --audit-level=moderate`; Dependabot proposes npm and GitHub Actions updates weekly. The workflow regression test asserts these hooks.
Release governance: a release checklist must map every external and local gate to evidence, include maintainer sign-off, and require protected-environment approval before the repository release variable can be enabled.
Public-source privacy check: search the exact candidate repository tree for personal usernames, local home paths, private hostnames/IPs, credentials, and temporary paths; sanitize evidence while retaining result semantics before first push.

Local commands: `npm ci`; `npm run check`; `npm run smoke:pack`; `npm run smoke:host -- <absolute OpenCode executable>`; `npm pack --dry-run --json`; `python .sdd/bin/agentic_sdd.py doctor .`; `python .sdd/bin/agentic_sdd.py check . production-readiness-public-release --target complete`.
