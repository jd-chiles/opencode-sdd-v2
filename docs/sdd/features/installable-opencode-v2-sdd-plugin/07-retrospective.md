# Retrospective
The installed SDK declarations are more precise than prose examples: list responses use data wrappers and interruption uses resume:false. A real provider-free host check found a packaging defect that fake-host tests could not: local directory loading probes index/server files directly, so a root index.js is necessary alongside npm exports. Host registries activate independently and asynchronously; smoke checks must wait for commands, agents and skills together. Windows junction fixtures need ordinary filesystem access and SQLite cleanup can require a short retry. Keep local approvals an explicitly documented trust convention rather than claiming human authentication. Preserve both raw and quoted argv when asserting native shell permissions so normal deny patterns still match.
