# Design
Status: Baseline
Repository was empty with unborn master. Follow project architecture. Deliver functional MVP plus conservative scheduler, not all speculative releases. One isolated workflow worktree preserves dependencies; serialize builders and parallelize read-only research. Use explicit model allowlists; never relax permissions or bypass provider restrictions. Approval is CLI-only, digest-bound; agents cannot self-approve.
Init installs pack files exclusively and leaves opencode.json(c) untouched. Doctor is offline; explicit /sdd-preflight probes minimal native child execution. Core persistence is injected; adapter uses native storage. Specs/config/plans are version controlled in .opencode-sdd. Recovery requires native-session idle inspection and explicit resume. Check commands are allowlisted and permission asserted. Review returns structured criteria verdicts; worker text is never process-test evidence. Git integration remains manual. Risks: API drift, ambiguous completion, concurrent commands, hanging checks, artifact drift. Mitigate with pinned types, bounded commands, lock and digest validation. Live smoke requires opt-in.
