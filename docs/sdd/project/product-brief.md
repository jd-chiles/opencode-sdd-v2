# Product brief
Status: Baseline
Deliver a locally installable OpenCode v2 plugin with a portable deterministic SDD engine. Users approve specs/plans, schedule single-level agents and require executable checks plus independent review. Implement the MVP and conservative dependency scheduling, parallel research, native worktree isolation and durable recovery. Advanced routing/metrics, nested teams, dashboards, cross-platform adapters and public publication are future work. No live model use, deployment, credentials or spend is authorized by this implementation.
